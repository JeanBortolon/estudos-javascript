Fundamentos de JavaScript

1. Introdução ao JavaScript
* O que é o JavaScript e para que serve?
O JavaScript é uma linguagem de programação que serve para adicionar interatividade, dinamismo e funcionalidades complexas a páginas web.

* Onde o JavaScript roda? Navegador e Node.js.
O Node.js é um ambiente de execução que permite rodar código JavaScript fora do navegador, e ele se relaciona com a linguagem ao utilizar o próprio motor (engine) V8 do JavaScript para executar aplicações no servidor.

* Como adicionar JavaScript em uma página HTML?
Você pode adicionar JavaScript usando a tag `<script>` diretamente no arquivo HTML, seja no cabeçalho ou no corpo. Também é possível vincular um arquivo externo utilizando o atributo `src` nessa mesma tag.

* No DevTools conseguimos verificar tanto as informações
do HTML, console, CSS, cookies, requisições HTTP em network e outras informações.

* A partir daqui as informações estão no arquivo script.js
